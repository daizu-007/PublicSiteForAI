01 — WHAT IT IS同じモデル、別の約束

Muse Spark 1.2 Contributorは、Standardと完全に同一のモデル。性能も、コンテキスト長も、ツール呼び出しの精度も変わらない。違うのは、プロンプトと出力が「製品改善のために利用される」ことに同意するかどうか。

  • 価格は Input $0.10 / Output $0.20（Standardは $1.25 / $4.25）
  • キャッシュ入力は $0.002 / 1M — 長文セッションが桁違いに安い
  • 推論は常時オン、出力トークンとして課金

02 — WHAT IT IS NOT無料の餌ではない

これはオープンソースでも、寄付でもない。明確なトレードオフだ。機密コード、個人情報、漏れてはいけないアイデアには向かない。その線引きができる人だけが、賢く使いこなせる。

  • 本番ワークロードには不向き。60 req/min のレート制限
  • 利用は Meta Model API 直結のみ。OpenRouter等の集約経由は不可
  • プロトタイプ、学習、個人プロジェクトに最適
